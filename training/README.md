# Training modules — index

Self-serve modules from the LUV Lab's onboarding sequence. Each is self-contained:
purpose, outline, hands-on exercises with answer keys, and a competence check a
supervisor can verify in minutes. **READY** modules are lab-verified; **DRAFT**
modules are complete and usable but still under internal review.

| Module | File | Status |
|---|---|---|
| Data ethics & privacy for research assistants | `data-ethics-for-ras.md` | READY |
| Praat / acoustic measurement basics | `praat-acoustics.md` | DRAFT |
| Forced alignment (MFA) | `forced-alignment-mfa.md` | READY |
| EEG session skills (capping, impedances, running participants) | `eeg-session-skills.md` | READY |
| Running the lab's EEG pipeline (config → CLI → QC) | `eeg-pipeline-run.md` | READY |

## Practice fixtures

- `practice-data/praat/` and `practice-data/mfa/` — synthetic fixtures for the Praat
  and MFA exercises, generated by the committed seed-fixed scripts beside them. The
  seeds and the modules' answer keys are coupled: regenerate with the committed
  scripts, never edit values by hand.
- `practice/eeg-pipeline/` — a complete practice run of the lab's EEG pipeline on two
  subjects from the openly licensed OpenNeuro dataset **ds007069** (CC0): config,
  fetch script, and real committed outputs the EEG modules' exercises read.

**No participant data from the lab's own studies appears anywhere in this
repository.** All fixtures are synthetic or derived from public, openly licensed
datasets.

## Not in this mirror (yet)

The lab's transcription and anonymization modules (Community cluster) and the R
module are part of the internal sequence but are not yet published here — they are
being prepared for public release. Some modules reference them, the lab handbook, or
internal project records; those references intentionally do not resolve in this
mirror.
