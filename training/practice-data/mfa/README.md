# practice-data/mfa/ — materials for Module 3 (forced alignment)

**Owner: undergrad-mentor.** Used by `people/training/forced-alignment-mfa.md`.

> **All data here is SYNTHETIC.** The transcript is invented, the alignment is
> generated by a script, and the coverage table is fabricated to a documented
> *pattern* (see below) with invented *numbers*. **No real participant
> recording, transcript, or metadata is used here, and none may ever be
> added.** Practice materials are synthetic or published only — see
> `people/training/data-ethics-for-ras.md`.

## Files

| File | What it is |
|---|---|
| `practice-aligned.TextGrid` | An MFA-style long-format TextGrid: a `words` tier and a `phones` tier, ARPABET labels with stress digits, 7.208 s. **Carries three seeded defects** arising from **two** root causes. This is Exercise 2. |
| `practice-transcript.lab` | The orthographic transcript the alignment claims to correspond to — the input side of the pair. |
| `oov-report.txt` | An out-of-vocabulary report of the kind an aligner emits at validation. One entry. **The exact filename an aligner writes is `[confirm]`** — this file is named for legibility, not to assert MFA's convention. |
| `alignment-coverage.csv` | Per-file coverage statistics for 12 synthetic recordings. This is Exercise 3, the sparse-alignment hunt. |
| `inspect_textgrid.py` | Standard-library TextGrid dumper, so you can do the exercises without Praat installed. **It is a viewing aid, not a QC tool** — it makes no judgement about whether an interval is right. |
| `make_practice_data.py` | Generator for all of the above. Standard library only. |

## Using the inspector

```bash
python3 inspect_textgrid.py practice-aligned.TextGrid
python3 inspect_textgrid.py practice-aligned.TextGrid --tier phones --min-dur 0.3
python3 inspect_textgrid.py practice-aligned.TextGrid --tier words --max-dur 0.05 --labelled-only
```

Praat is the better view when you have audio, because you can see the interval
against the spectrogram. Use the inspector when you do not.

## Regenerating

These files are **machine-written**. Per the lab's provenance norm, never
hand-edit them — change the generator and re-run:

```bash
python3 make_practice_data.py
```

The generator asserts that both tiers span the same interval with no gaps, so
a broken edit fails loudly rather than silently. **If you change the utterance
or the seeded defects, the module's answer key stops matching** — update both
together or not at all.

## Provenance of the coverage exercise

`alignment-coverage.csv`'s *failure pattern* — an alignment that covers only a
few words per minute and stops partway through the file — is drawn from a real,
documented lab event: the PREP corpus shipped an `MFA_Aligned_TextGrids/`
directory whose words tier carried only **1.8–8.2 words per minute** and
stopped partway through each interview, so it was rejected and the corpus was
re-aligned from the verbatim transcripts. See
`projects/p-oh-lowering/methods/extraction-and-measurement.md` §1.1.

**The numbers in the CSV are synthetic.** Only the shape of the failure is real.
