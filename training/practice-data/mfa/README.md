# practice-data/mfa/ — materials for Module 3 (forced alignment)

**Owner: undergrad-mentor.** Used by `people/training/forced-alignment-mfa.md`.

> **All data here is SYNTHETIC.** The transcript is invented, the alignment is
> generated by a script, and the coverage and alignment-analysis tables are
> fabricated to documented *patterns* (see below) with invented *numbers*.
> **No real participant recording, transcript, or metadata is used here, and
> none may ever be added** — that includes real alignment-analysis output,
> which carries per-speaker identifiers and acoustic metadata about real
> people. Practice materials are synthetic or published only — see
> `people/training/data-ethics-for-ras.md`.

## Files

| File | What it is |
|---|---|
| `practice-aligned.TextGrid` | An MFA-style long-format TextGrid: a `words` tier and a `phones` tier, 7.208 s. Follows **MFA 3.x output conventions** — silence is **unlabelled on both tiers**, words are **lowercase**, and phone labels are **ARPABET with stress digits**, as the `english_us_arpa` models emit. *(An `english_mfa` alignment uses IPA-style phone symbols instead: same structure, different symbols.)* **Carries three seeded defects** arising from **two** root causes. This is Exercise 2. |
| `practice-transcript.lab` | The orthographic transcript the alignment claims to correspond to — the input side of the pair. |
| `oov-report.txt` | An out-of-vocabulary report of the kind an aligner emits at validation. One entry. **This file is named for legibility.** MFA itself writes `oovs_found_<dictionary>.txt` and `oov_counts_<dictionary>.txt` (plus `utterance_oovs.txt`) into the directory you pass to `mfa validate --output_directory`. |
| `alignment-coverage.csv` | Per-file coverage statistics for 12 synthetic recordings. This is Exercise 3, the sparse-alignment hunt. |
| `alignment-analysis-practice.csv` | An MFA-style **alignment-analysis** table — 14 rows, one per utterance, across 7 files. Carries `file`, `begin`, `end`, `speaker`, `overall_log_likelihood`, `speech_log_likelihood`, `phone_duration_deviation` and `snr`; a real MFA 3.4 file has ten columns, with `max_running_short_interval` between the deviation and `snr` and `intensity_deviation` at the end. Seeded with the three triage patterns: **empty metric columns** (`interview04`), a **`phone_duration_deviation` far above the cohort** (`interview06`), and **low `snr`** (`interview02`). This is Exercise 5. **Every value is invented** — only the column structure and the patterns come from real practice. |
| `inspect_textgrid.py` | Standard-library TextGrid dumper, so you can do the exercises without Praat installed. **It is a viewing aid, not a QC tool** — it makes no judgement about whether an interval is right. |
| `make_practice_data.py` | Generator for all of the above. Standard library only. |

## Using the inspector

```bash
python3 inspect_textgrid.py practice-aligned.TextGrid
python3 inspect_textgrid.py practice-aligned.TextGrid --tier phones --min-dur 0.3
python3 inspect_textgrid.py practice-aligned.TextGrid --tier words --max-dur 0.05 --labelled-only
```

Praat is the better view when you have audio, because you can see the interval
against the spectrogram. Use the inspector when you do not.

## Regenerating

These files are **machine-written**. Per the lab's provenance norm, never
hand-edit them — change the generator and re-run:

```bash
python3 make_practice_data.py
```

The generator asserts that both tiers span the same interval with no gaps, so
a broken edit fails loudly rather than silently. **If you change the utterance
or the seeded defects, the module's answer key stops matching** — update both
together or not at all.

## Provenance of the coverage exercise

`alignment-coverage.csv`'s *failure pattern* — an alignment that covers only a
few words per minute and stops partway through the file — is drawn from a real,
documented QC event in the lab's own corpus work: a shipped alignment whose
words tier carried a small fraction of the words actually spoken and stopped
partway through each recording, so it was rejected and the corpus re-aligned
from the verbatim transcripts. The module tells that story as a lesson in §5.3.

**The numbers in the CSV are synthetic.** Only the shape of the failure is real.
